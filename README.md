# WizCont - Contagem de ligações - Wizard

![Social preview do github](./public/social-preview.png)

## Sobre o projeto

O **WizCont** foi desenvolvido para a contagem de ligações do setor comercial da empresa Wizard by Pearson (filial de Lins), na qual trabalho atualmente como recepcionista. O intuito é deixar a contagem mais rápida, precisa e padronizada.

O projeto começou como um script simples feito em Python apenas para uso pessoal, e depois a gerência comercial pediu que eu desenvolvesse um sistema que pudesse ser utilizado em outras filiais.

## Bibliotecas e ferramentas utilizadas

- [React](https://react.dev/) com [Vite](https://vite.dev/) para desenvolvimento front-end
- [tailwindcss](https://tailwindcss.com/) para estilização
- [react-dropzone](https://react-dropzone.js.org/) para área de upload do relatório de ligações
- [react-icons](https://react-icons.github.io/react-icons/) para ícones
- [Lucide](https://lucide.dev/) também para ícones e confecção do favicon
- [Papa Parse](https://www.papaparse.com/) para análise do relatório em `.csv`
- [Vercel](https://vercel.com/) para deployment do site
